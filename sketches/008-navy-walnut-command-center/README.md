## Variant: Navy + Walnut Command Center (Preferred Direction)

### Design stance
The clean, preferred direction: deep navy utility bar at the top, warm walnut-and-brass nav below. Restrained and hospitality-native without competing colors fighting for attention.

### Key choices
- Top bar: deep navy (#1d2432) — reads as a calm, technical layer above the warm brand elements.
- Walnut nav: full brass/walnut gradient with the Origen "O" medallion, brass separator lines, and live sync status.
- Body: cream panels, Cormorant headlines, Syne sans for data — the same warm-scholarly palette as the guest traceability page.
- POS status: Toast synced (updated from Square to reflect actual stack decision).
- Nav tabs: Today · Sales · Food Cost · Invoices · Menu · Staff · Automations.

### Content blocks
- Morning brief + daily metrics (Gross sales, Covers, Attention count)
- Needs eyes: alert list (cash variance, COGS flag, clean items)
- Four data streams: Sales · Labor · Food Cost · Banking
- Top items and Automation queue side-by-side

### Trade-offs
- Strong at: two distinct registers — navy reads as "system," walnut reads as "restaurant." The contrast makes the topbar recede and the nav feel like craft.
- Weak at: if Casa Origen's final brand uses strong green, a green nav variant (sketch 006) better reinforces that.

### Best for
The operator-facing management dashboard. Primary demo artifact alongside the guest traceability page (sketch 007).
