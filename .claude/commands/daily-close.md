# /daily-close-with-traceability

Run the daily close for Casa Origen. Pulls yesterday's sales, reconciles deposits, flags anomalies, and generates a full ingredient traceability map. Outputs a morning ops note to `outputs/`.

---

## Step 1 — Establish the date

Use today's date minus one day as the close date, unless the user specifies otherwise.

```
Close date: YYYY-MM-DD
```

Confirm with the user before proceeding if the date is ambiguous.

---

## Step 2 — Pull sales data

Call the POS adapter tools:

- `get_sales_summary(date)` → full day summary
- `get_sales_flags(date)` → voids, comps, discounts, deposit variances
- `get_top_items(date, 5)` → top 5 items by revenue

---

## Step 3 — Reconcile deposits

Check `deposit_variance` in the sales summary:
- **Zero:** clean. Note it.
- **Positive:** over. Rare — note it.
- **Negative:** short. Flag clearly. Include the amount and note from the flags data.

---

## Step 4 — Flag anomalies

Review all flags from `get_sales_flags`. For each flag:
- **void:** Note amount and reason. Flag if > $50 or no reason given.
- **comp:** Note amount and reason. Flag if > $100 or no reason given.
- **discount:** Note total discount. Flag if > 5% of gross sales.
- **deposit_variance:** Always flag. Include recommended action.

---

## Step 5 — Pull traceability map

Call `get_traceability_map(date)` from the traceability server.

Summarize:
- How many unique farms sourced today
- Which certifications were represented
- Whether all ingredients are fully lot-tracked
- Any ingredients that are untracked (lot_number = 'LOT-UNTRACKED')

---

## Step 6 — Check for price alerts

Load this week's invoice data and check `week_totals.alerts` for any active price alerts.

Highlight any ingredients with price increases > 5% and note the affected menu items.

---

## Step 7 — Write the ops note

Write a clean, readable ops note to `outputs/daily-close-YYYY-MM-DD.md` in this format:

```markdown
# Daily Close — [Day], [Date]
*Casa Origen · 937 Central Ave, St. Petersburg FL*

---

## Sales Summary

| Metric | Value |
|--------|-------|
| Covers | X |
| Gross Sales | $X,XXX.XX |
| Discounts | $X.XX |
| Voids | $X.XX |
| Comps | $X.XX |
| Cash Deposit (expected) | $X,XXX.XX |
| Cash Deposit (actual) | $X,XXX.XX |
| **Variance** | **$X.XX ✓ / ⚠️ Short $X.XX** |

**Top Items**
1. [Item] — X sold · $XXX revenue
2. ...

---

## Flags

[List each flag with type, amount, and note. Use ⚠️ for items needing attention.]

---

## Sourcing Today

**[N] farms on the plate today**

| Farm | Location | Certifications | Dishes |
|------|----------|----------------|--------|
| Worden Farm | Punta Gorda, FL | USDA Organic | Origen Bowl, Green Farm Scramble, ... |
| ...  |

**Traceability status:** ✅ Fully traceable / ⚠️ [X] ingredients untracked

---

## Price Alerts

[If none: "No price movement this week."]
[If alerts: list ingredient, % change, affected dishes]

---

## Actions Required

[Numbered list of anything that needs a human decision or follow-up today]

---

*Generated by Origen Backend · Synthetic data*
```

---

## Step 8 — Confirm output

Tell the user:
- Where the file was saved
- How many actions require attention
- Whether sourcing is fully traceable

Then ask: **"Anything you'd like to dig into further?"**
